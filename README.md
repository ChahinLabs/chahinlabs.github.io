# chahinlabs.github.io

Static site for Chahin Labs / SabrosuraSmash (GitHub Pages). No build step, no trackers.

Deploy: create public repo `chahinlabs.github.io` under the `chahinlabs` GitHub account, upload all files in this folder to the repo root (keep `.nojekyll`). Pages serves it at https://chahinlabs.github.io/ (Settings → Pages → Deploy from branch `main`, `/ (root)`).

TikTok URL-prefix verification: put the downloaded `tiktok-developers-site-verification` file (e.g. `tiktok<random>.txt`) in the repo root, commit, then click Verify in the TikTok developer portal.

Pages: index.html, privacy.html, terms.html, style.css.
